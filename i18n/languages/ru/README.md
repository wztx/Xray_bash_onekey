## 功能特性

* 输入 `idleleo` 打开 Xray 管理菜单，管理安装、服务、安全设置等
* 采用 Qwen-MT-Plus AI 实现多语言精准翻译
* 支持 Reality 协议，建议搭配 Nginx 前置（脚本内可安装）
* 支持 WebSocket、gRPC、xHTTP 传输，可选择单一传输或 `ws+gRPC+xHTTP` 同时启用
* 支持 IPv4 / IPv6 双栈：安装时可自动检测公网出口能力，按域名 A/AAAA 记录独立校验并生成对应分享链接与 Clash 配置
* 内置 fail2ban 防护（脚本内可安装）
* 内置 Xray 流量统计、流量阻断、GeoIP/GeoSite 规则更新及定时更新
* 支持脚本、Xray、Nginx 和证书更新，并为关键更新提供备份与失败回滚
* Текущая работающая конфигурация будет автоматически скопирована перед переустановкой и переключением режимов, а исходная конфигурация будет восстановлена ​​в случае сбоя.
* 重配置提供三条安全路径：保留配置重新部署、标准模板重建、模式切换
* 采用 [@DuckSoft](https://github.com/DuckSoft) 的分享链接[提案](https://github.com/XTLS/Xray-core/issues/91)（beta），兼容 Qv2ray、V2rayN、V2rayNG
* 采用 [XTLS](https://github.com/XTLS/Xray-core/issues/158) 提案，遵循 [UUIDv5](https://tools.ietf.org/html/rfc4122#section-4.3) 标准，支持自定义字符串映射至 VLESS UUID
* 支持 gRPC 协议：[使用 gRPC 协议](https://hey.run/posts/xrayjin-jie-wan-fa---shi-yong-grpcxie-yi)
* Поддерживает балансировку нагрузки Reality/ws/gRPC/xHTTP:
  - [部署 Reality 负载均衡](https://hey.run/posts/bushu-reality-balance)
  - [搭建后端负载均衡](https://hey.run/posts/xrayjin-jie-wan-fa---da-jian-hou-duan-fu-wu-qi-fu-zai-jun-heng)
* Режим Reality + Nginx включен по умолчанию. SNI Guard: неизвестный SNI, пустой SNI и исключение TLS не попадут в серверную часть Xray Reality. Стратегия изоляции (ssl_reject_handshake) применяется по умолчанию. Опытные пользователи могут переключиться на самостоятельно созданный резервный сайт decoy или напрямую TCP Отказано. Эта функция используется для уменьшения активного обнаружения и воздействия неправильной конфигурации и не обеспечивает идеальную маскировку.

## 准备工作

* 一台境外服务器，具备公网 IP
* Установите протокол Reality: вам необходимо подготовить целевое доменное имя, соответствующее требованиям Xray.
* Установите версию TLS: Вам необходимо подготовить доменное имя и правильно настроить записи A и/или AAAA в соответствии с доступной сетью сервера; для сред с двумя стеками рекомендуется одновременно настроить правильные A и AAAA. Скрипт поддерживает автоматическое определение сетевых возможностей IPv4/IPv6. Если доступен двойной стек, соответствующая запись клиента может быть создана одновременно.
* 阅读 [Xray 官方文档](https://xtls.github.io), понимать понятия, связанные с Reality, TLS, WebSocket, gRPC и Xray.
* **Убедитесь, что curl установлен: CentOS пользовательское выполнение.`yum install -y curl`;Debian/Ubuntu Пользовательское выполнение`apt install -y curl`

## 安装模式

| модель | иллюстрировать |
|------|------|
| Reality + Nginx | Рекомендуемый режим: вы можете подключить простой протокол ws/gRPC/xHTTP, необходимый для балансировки нагрузки. |
| Nginx + TLS | Поддержка ws/gRPC/xHTTP, автоматическая подача заявки и продление сертификата Let's Encrypt |
| ws/gRPC/xHTTP ONLY | Независимый входящий режим без TLS, в основном используется в сценариях серверной части или балансировки нагрузки. |
| XTLS ONLY | Используется только в определенных сценариях, таких как передача трафика. |
| Docker | Xray, Nginx и основной скрипт предустановлены в образе |

Необязательно при установке режимов, связанных с ws/gRPC/xHTTP.`ws`、`gRPC`、`xHTTP`или`ws+gRPC+xHTTP`. Скрипт сгенерирует соответствующий порт, путь, ссылку для совместного использования и QR-код соответственно; Clash в настоящее время не поддерживает xHTTP, и сценарий выдаст запрос в выходных данных конфигурации.

## Инструкция по перенастройке

При повторной установке установленной среды сценарий автоматически создаст резервную копию текущей работающей конфигурации и предоставит три пути реконфигурации:

| путь | иллюстрировать | предел |
|------|------|------|
| Сохранить перераспределение конфигурации | Сохраняйте пользовательскую routing/outbounds/DNS и многопользовательскую конфигурацию, изменяйте только выбранные пользователем поля (порты, пути, параметры UUID, Reality и т. д.). | Изменения структуры передачи (например, ws → gRPC) не поддерживаются. Если вам необходимо изменить комбинацию трансмиссии, воспользуйтесь стандартным шаблоном для ее восстановления. |
| Стандартная реконструкция шаблона | Создайте стандартную конфигурацию шаблона, используя текущие повторно используемые параметры, пользовательский routing/outbounds/DNS можно удалить. | Не обязательно, чтобы количество пользователей оставалось неизменным. |
| Переключатель режима | Переключитесь в другой режим протокола (например, Reality → TLS). По умолчанию повторно используется только основной пользователь UUID/email. | Другие пользователи не будут автоматически перенесены, и перед переключением им будет предоставлен четкий запрос. |

Если на каком-либо этапе процесса реконфигурации произойдет сбой (запись конфигурации, запуск службы, проверка работоспособности и т. д.), произойдет автоматический откат к исходной резервной конфигурации. Каталог резервных копий использует уникальную временную метку для поддержки нескольких последовательных реконфигураций без конфликта друг с другом.

## RillML Xray AI Помощник по эксплуатации и техническому обслуживанию

RillML (сокращенно Rill) обеспечивает возможности локальной адаптивной интеллектуальной эксплуатации и обслуживания для Xray.

Встроенный локальный помощник по эксплуатации и техническому обслуживанию AI контролирует состояние здоровья Xray/Nginx в режиме реального времени, автоматически диагностирует неисправности и дает рекомендации по лечению без необходимости использования внешнего API. Вход в главное меню`9`или выполнить`idleleo --rill-agent`Входить.

**Основные компетенции**

* Мониторинг: наблюдение в режиме реального времени за состоянием службы и конфигурации Xray/Nginx.
* Диагностика: Определите основную причину неисправности с рекомендациями по достоверности (высокая/средняя/низкая/недостаточная доказательность).
* Решение: автоматически определить тип неисправности и дать рекомендации по ее устранению. В инструкции четко указано, что автоматическая обработка разрешена или даны только предложения.
* Режим: интеллектуальное суждение/только наблюдение/безопасная деактивация, система не будет изменена, пока не будет включена автоматическая модификация.

**Часто используемые команды**

| действовать | Заказ |
|------|------|
| Откройте меню помощника по эксплуатации и техническому обслуживанию AI. | `idleleo --rill-agent` |
| Установите или отремонтируйте механизм принятия решений AI. | `idleleo --rill-agent-install` |
| Проверьте статус решения AI | `idleleo --rill-agent-status` |
| Запустите AI устранение неполадок | `idleleo --rill-agent-diagnose` |
| Механизм проверки AI | `idleleo --rill-agent-verify` |
| Деактивация безопасности AI решение | `idleleo --rill-agent-safe-disable` |
| Удалить механизм Rill AI | `idleleo --rill-agent-uninstall` |

AI Механизм принятия решений все еще находится на стадии тестирования. Рекомендуется сосредоточиться на диагностических предложениях. По умолчанию система не будет автоматически изменена.

## AI Skill 部署

Поддерживает автоматическое развертывание Xray с помощью инструментов AI, таких как Trae, без ручного взаимодействия. Посмотреть подробности[Xray_bash_onekey_skill](https://github.com/hello-yunshu/Xray_bash_onekey_skill)。

Традиционный метод требует, чтобы SSH зашел на сервер, запустил сценарий установки и ответил на интерактивные вопросы один за другим; методу Skill нужно только сообщить AI о ваших потребностях, а AI автоматически сгенерирует неинтерактивный скрипт и выполнит его, напрямую возвращая ссылку VLESS.

**Поддерживаемые режимы**: Reality / TLS / ws ONLY / XTLS ONLY

**Как использовать**: Просто скажите «Помогите мне собрать Xray на сервере» в инструменте AI, поддерживающем Skill, и AI автоматически соберет информацию, сгенерирует сценарии, выполнит развертывание и вернет информацию о соединении.

## На что следует обратить внимание

* Если вы не понимаете значение каждого параметра, используйте значение по умолчанию, за исключением обязательных полей (просто нажмите Enter).
* Cloudflare Пользователи, откройте CDN после завершения установки.
* Этот сценарий требует базовых знаний Linux и знаний компьютерной сети.
* Поддерживает Debian 12+ / Ubuntu 24.04+ / CentOS Stream 10+, некоторые шаблоны CentOS могут иметь проблемы с компиляцией, при возникновении проблем рекомендуется сменить систему
* Рекомендуется развернуть на одном сервере только один агент и использовать порт по умолчанию 443.
* Пользовательское сопоставление строк с UUIDv5 требует поддержки клиента.
* Рекомендуется использовать его в чистой среде; новичкам не следует использовать CentOS
* Эта программа зависит от Nginx, прошло[LNMP](https://lnmp.org)Пользователям, установившим скрипт Nginx, обратите внимание на возможные конфликты.
* Общая ссылка xHTTP предназначена для клиентов, поддерживающих xHTTP; В выводе конфигурации Clash будет пропущен xHTTP.
* Не используйте этот сценарий в производственной среде без проверки доступности.
* Автор: Юн Шу, оказывает лишь ограниченную поддержку.

## Конфигурация сертификата

Обратите внимание на центр сертификации и срок действия. По истечении срока действия пользовательского сертификата вам необходимо продлить его самостоятельно.

**Автоматический сертификат**: скрипт поддерживает автоматическое создание сертификатов Let's Encrypt (действителен в течение 3 месяцев) и теоретически поддерживает автоматическое продление.
